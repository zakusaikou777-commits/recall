# Recall — 復習ブックマーク（Chrome 拡張機能）

ワンクリックで今見ているページを保存し、**カテゴリ・タグ・状態**で整理して、
**忘却曲線**に沿ったタイミングで復習を通知する Chrome 拡張機能です。

reminDO のような間隔反復の仕組みはそのままに、「分類できない」「昔保存したものが探せない」を解消することを目的にしています。

---

## インストール

1. このフォルダ（`recall`）をパソコンの好きな場所に置く（例：`ドキュメント/recall`）
   ※ ZIP のまま読み込むことはできません。必ず**展開**してください。
2. Chrome で `chrome://extensions` を開く
3. 右上の **デベロッパーモード** を ON
4. 左上の **「パッケージ化されていない拡張機能を読み込む」** をクリック
5. 手順1で置いた `recall` フォルダを選択
6. ツールバーのパズルアイコンから Recall を **ピン留め** しておくと便利です

> v1.9.0 から拡張機能の ID を固定しています（ID: `kcgmjcokekapobnjijclhlhnaccdpkpp`）。
> フォルダを移したり別の PC に入れたりしても同じ拡張機能として扱われ、データと同期がつながったままです。
> ただし Chrome から拡張機能を「削除」すると、この PC のデータも消えます。
> 消えても戻せるように、[Google ドライブ同期](#google-ドライブ同期) をおすすめします。
>
> Edge / Brave / Vivaldi などの Chromium 系ブラウザでも同じ手順で動きます（Google ドライブ同期だけは Chrome 専用です）。

### v1.8 以前から上げるとき（1回だけ）

v1.9.0 で拡張機能の ID が変わるため、**古い Recall のデータは新しい Recall からは見えません**。次の順で移してください。

1. **古い Recall** のライブラリ → ⚙ 設定 →「JSONで書き出し」
2. 新しい版のフォルダを（古いフォルダとは別の場所に）置き、「パッケージ化されていない拡張機能を読み込む」で追加
3. **新しい Recall** のライブラリ → ⚙ 設定 →「JSONを読み込み」で 1. のファイルを選ぶ
   （「設定も置き換えますか？」と聞かれたら OK。気になり帳の送り先 URL などの設定も引き継がれます）
4. 「気になり帳へ送る」を使っているなら、新しい Recall の ⚙ 設定 →「保存の確認を許可する」をもう一度押す
   （許可は拡張機能ごとなので引き継がれません）
5. 全部そろったのを確かめてから、古い Recall を `chrome://extensions` で削除

古い方を先に削除・上書きすると、書き出す前のデータが消えます。必ず 1. を先に行ってください。

## 使い方

### 保存する

| 操作 | 内容 |
|---|---|
| ツールバーのアイコン / **Alt+S** | 保存パネルを開く（カテゴリ・タグ・メモ・間隔を指定して保存） |
| **Alt+Shift+D** | 確認なしでその場で保存（前回そのサイトで使ったカテゴリを自動適用） |
| 右クリック → 「このページを Recall に保存」 | ページ・リンクを保存 |

- 保存済みのページで開くと**編集モード**になり、次の復習日の表示と「覚えた／まだ」ボタンが出ます。
- URL は `utm_*` などの追跡パラメータを無視して重複判定するので、同じ記事を二重に登録しません。

### YouTube と画像

YouTube のリンクはそのまま保存できます。加えて次のことをします。

- **サムネイル・チャンネル名・再生時間**を自動で表示します
- サムネイルの ▶ を押すと、**ライブラリを離れずにその場で再生**できます（`youtube-nocookie.com` を使用）
- `watch?v=` / `youtu.be` / `shorts` / 時間指定つき / プレイリスト内 — **URL の形が違っても同じ動画は 1 件にまとめます**

YouTube 以外のページも、保存時に OGP 画像（記事のアイキャッチ）があればサムネイルとして表示します。

> **画像データは保存していません。** 保存するのは画像の URL だけ（1件あたり数十〜数百バイト）で、
> YouTube に至っては動画 ID からサムネイルの URL を組み立てるので **0 バイト**です。
> そのぶん、表示のときに元のサイトへ画像を取りに行きます。気になる場合は設定でサムネイルをオフにできます。
> ページ情報の読み取りは、保存操作をしたその瞬間・そのタブだけに限られます（`activeTab`）。

### 探す

| 操作 | 内容 |
|---|---|
| **Alt+Shift+S** | ライブラリを開く |
| ライブラリの検索窓（**/** キー） | タイトル・URL・メモ・タグを横断検索（スペース区切りで AND 検索） |
| アドレスバーで **`rc`** + スペース + キーワード | 保存したページを直接検索して開く |
| 左サイドバー | 今日の復習／未読／学習中／お気に入り／完了／アーカイブ、カテゴリ、タグで絞り込み |

### 復習する

- 保存すると翌日が最初の復習予定になり、期限が来るとアイコンにバッジ、1日1回通知が出ます。
- 「今日の復習」→ **順番に復習する** で 1件ずつ集中モード。
  キーボードは **1** = まだ / **2** = あとで / **3** または **Space** = 覚えた / **Esc** = 終了。
- 「覚えた」を押すたびに間隔が **1 → 3 → 7 → 14 → 30 → 60 → 120 日** と広がり、最後まで進むと **完了**。
- 「まだ」で最初の間隔に戻ります（設定で「1段階だけ戻す」に変更可）。
- 項目ごとに「毎日／毎週／毎月…」の固定間隔を選ぶこともできます。

## 気になり帳へ送る（スマホから見る）

Chrome 拡張機能はスマホでは動きません。スマホでも同じものを見たい場合は、
保存したページを **気になり帳（kininari.html）** にも送ります。
気になり帳は Google ドライブで同期されるので、スマホのブラウザからそのまま見られます。

**設定のしかた**

1. ライブラリ右上の ⚙ 設定 →「気になり帳へ送る」をオン
2. 気になり帳の URL を入れる（例：`https://yourname.github.io/app/kininari.html`）
3. おすすめ：「保存の確認を許可する」を押す
   （押すと、保存が終わったのを確かめてから裏で開いたタブを閉じます。気になり帳の容量がいっぱいで保存できなかったときは、その理由も出ます。
   押さなくても送信は動きますが、保存できたかは分かりません）
4. 既存の **「気になり帳クリッパー」は外してください**。両方入れたままだと同じページが二重に保存されます。

**送られ方**

| Recall | 気になり帳 |
|---|---|
| カテゴリ | 同じ名前の**フォルダ**（無ければ作られます）。気になり帳のフォルダは、設定の「カテゴリの管理」→「気になり帳のフォルダを取り込む」で Recall のカテゴリに足せます |
| タグ | 気になり帳のタグになります（v33 より前の版では本文末尾の `#タグ` として残ります） |
| メモ | メモ本文 |
| サムネイル（YouTube・OGP画像） | メモ本文の先頭の画像 |
| 復習の予定 | 段位・次回の予定・回数まで送られます（気になり帳 **v33 以降**が必要。それより古い版では無視されます） |

気になり帳 v33 以降なら、送ったあとはスマホでも「今日の復習」に並び、そこで答えた結果も
ドライブ同期でほかの端末に伝わります。

送るのは**新しく保存したときだけ**です。あとから内容を直しても送り直しません
（気になり帳側に同じものが積み上がらないようにするため）。過去に保存した項目を送りたいときは、
そのページでポップアップを開いて「気になり帳へ送る」を押してください。

> 送信は、気になり帳を裏のタブで一瞬開いて保存させる方式です（既存のクリッパーと同じ仕組み）。
> 保存が終わるとタブは自動的に閉じます。ブラウザを閉じるなどで取り残されたタブも、次回起動時に片付けます。

**送れなかったときは**

URL の打ち間違い・オフライン・裏のタブを閉じた、などで送信は失敗します。
そのとき項目は**「送信済み」にはならず**、未送信として残り、**5分ごとに自動で送り直します**
（保存先URLを直したときや Chrome を開き直したときにも、すぐ送り直します）。

設定の「気になり帳へ送る」に、未送信の件数・中身・失敗した理由と「今すぐ送る」が出ます。
ポップアップにもその項目の状態が出ます。

| 表示 | 意味 |
|---|---|
| 送信済み | 気になり帳が保存し終えたことを確認できた（「保存の確認を許可する」を押している場合） |
| 送信済み（未確認） | 気になり帳を開いたが、保存できたかは確かめていない |
| 送信待ち | まだ送れていない。自動で送り直します |
| 送れていません | 5回失敗したので自動での送り直しを止めた。気になり帳の容量不足・形式エラーのときもここに入り、理由が出ます。「今すぐ送る」で再開できます |

送り直すときは、前と同じ番号（クリップの番号）で送ります。前の送信が実は届いていた場合、気になり帳は2件目を作らず
「もう入っている」と返すので、二重に登録されません（気になり帳の側で、番号を30日・500件まで覚えています）。

## Google ドライブ同期

Chrome にログインしている Google アカウントの**ドライブ**に全件を置いて、つないだ PC 同士で同期します。

- 置き場所は、ドライブの「アプリ専用の領域」です（ドライブの画面には出ず、ほかのアプリからは読めません）。
  Recall が見られるのもこの領域だけで、あなたのほかのファイルには触れません。
- **全件**（メモ・タグ・復習の進み具合・サムネイル情報・削除）が同期されます。Chrome の同期のような 300 件の上限はありません。
- 拡張機能を削除した・PC を入れ替えた、というときも、設定で「Google ドライブにつなぐ」を押すだけで戻ります。
- 1日1回、その日の状態を**7日分**残します。設定の「ドライブのバックアップから戻す」で、選んだ日の状態から無くなった項目を読み込めます。
- 変更は1分ほどあとに送られます。ほかの PC の変更は、30分ごと・ライブラリを開いたとき・「今すぐ同期」で取り込みます。
- Google の許可が切れるなどで同期が止まったら、**通知で知らせます**（1日1回まで）。通知を押すと設定が開くので、「つなぎ直す」を押してください。
  止まっている間も、データはこの PC に残っています（同期が止まるだけで、消えることはありません）。
- 設定 →「同期をやめる」でいつでも止められます。ドライブに置いたデータは残ります
  （消したいときは Google ドライブ → ⚙ 設定 → アプリを管理 → Recall →「非表示のアプリデータを削除」）。

### Google ドライブ同期の準備（最初に1回だけ・10〜15分）

Google に「この拡張機能がドライブを使ってよい」と登録する作業です。無料です。

> **日記帳・気になり帳で Google ドライブ同期を使っているなら**、そのとき作った Google Cloud プロジェクト
> （日記の ❓ヘルプに出ている「現在のクライアントID」があるプロジェクト）をそのまま使えます。
> Drive API の有効化と、同意画面のスコープ（`drive.appdata`）は済んでいるので、**手順 5〜8 だけ**で足ります。
> 置き場所（アプリ専用の領域）は日記帳・気になり帳と共有になりますが、ファイル名で分かれていて、互いのファイルには触れません。
> 日記用の「ウェブ アプリケーション」のクライアントはそのまま残し、Recall 用に**別のクライアントを1つ足して**ください。

1. [Google Cloud コンソール](https://console.cloud.google.com/) を開き、新しいプロジェクトを作る（名前は `Recall` など）
2. 「API とサービス」→「ライブラリ」で **Google Drive API** を検索して「有効にする」
3. 「Google Auth Platform」（または「OAuth 同意画面」）を開き、案内に沿って入力する
   - アプリ名：`Recall`、ユーザーサポートメール：自分のアドレス
   - 対象（ユーザーの種類）：**外部**
   - 連絡先：自分のアドレス
4. 「データアクセス」（スコープ）で `.../auth/drive.appdata` を追加する
5. 「対象」（Audience）で公開ステータスを **本番環境（In production）にする**
   - テスト中のままだと、許可が7日ごとに切れて、つなぎ直しが必要になることがあります
   - Recall だけのプロジェクトなら、`drive.appdata` は「機密性の低いスコープ」なので Google の審査は要りません
   - 日記帳と同じプロジェクト（カレンダー・タスクのスコープも入っている）では、本番環境にしても審査なしで使えますが、
     許可の画面に「このアプリは確認されていません」と出ます。日記帳と同じく「詳細」→「（アプリ名）に移動」で進めます
   - テスト中のままにする場合は、「テストユーザー」に自分のアカウントが入っていることを確かめてください
6. 「クライアント」→「クライアントを作成」
   - アプリケーションの種類：**Chrome 拡張機能**
   - アイテム ID：`kcgmjcokekapobnjijclhlhnaccdpkpp`（`chrome://extensions` の Recall の ID と同じか確かめてください）
7. できた **クライアント ID**（`xxxx.apps.googleusercontent.com`）を `manifest.json` の
   `oauth2.client_id` に書き、`chrome://extensions` で Recall を再読み込みする
   （このリポジトリの `manifest.json` には設定済みです。別の Google Cloud プロジェクトを使うときだけ書き換えてください）
8. ライブラリ → ⚙ 設定 →「Google ドライブ同期」→「**Google ドライブにつなぐ**」

2台目以降の PC では、Chrome の同期で「つなぐ」設定も届くので、Recall を入れるだけで自動でつながります
（つながらないときは、その PC でも「Google ドライブにつなぐ」を押してください）。

## データの保存先とバックアップ

**本体はこの PC に保存されます（容量無制限）。そのうち更新が新しいものだけを Chrome アカウントで同期します。**
Google ドライブ同期をつなぐと、全件がドライブにも置かれます。

Chrome の同期ストレージには 約100KB・510件 という小さな上限があるため、
全部を同期に置くとすぐ埋まってしまいます。そこで Recall は二段構えにしています。

| どこに | 何が | 上限 |
|---|---|---|
| この PC（ローカル） | **全項目**とサムネイル情報 | 実質なし |
| Chrome アカウント（同期） | 更新が新しい順に **最大300件**（設定で変更可） | 100KB |
| Google ドライブ（つないだとき） | **全項目**・削除の記録・カテゴリと設定、日ごとのバックアップ7日分 | ドライブの空き容量 |

- 何件保存しても保存に失敗しません。同期に載らなかった古い項目も、この PC では今までどおり検索・復習できます。
- 別の PC では「同期された分」が見えます。全部を持っていきたいときは JSON で書き出して読み込んでください。
- 同期そのものを切ることもできます（設定 → 同期）。
- ライブラリ左下に「保存件数」と「うち何件を同期中か」が出ます。

設定 → **バックアップ / 移行** から

- **JSON で書き出し** … 全項目＋設定のバックアップ（読み込みで復元・移行できます）
- **CSV で書き出し** … Excel / スプレッドシートで開ける一覧
- **JSON を読み込み** … バックアップの復元。`{ items: [{ url, title, note, tags }] }` 形式でも取り込めます。
  すでに保存してあるページ（同じ項目・同じ URL）は読み込まないので、同期で届いた分が二重になることはありません。
  バックアップの設定がいまと違うときは、設定も置き換えるか尋ねます
- **すべて削除** … 同期オン（または Google ドライブ同期中）なら、ほかの PC とドライブからも消えます。同期オフなら、この端末の項目だけを消します。
  ドライブの日ごとのバックアップは残るので、間違えて消したときはそこから戻せます

上限が近づいたら、書き出してから完了済み項目を削除・アーカイブすると余裕ができます。

## 設定でできること

- サムネイル画像を表示するかどうか / YouTube をその場で再生できるようにするか
- Chrome アカウントで同期するかどうか、同期する件数の上限
- 復習間隔の日数列（例：`2, 5, 14, 45`）
- 保存してから最初の復習までの日数
- 「まだ」を押したときの戻り方
- 通知の ON/OFF、通知する時刻、バッジ表示
- 保存時の既定カテゴリ・既定の間隔
- カテゴリの追加・名前変更・色変更・削除（削除すると中身は先頭のカテゴリへ移動）

ショートカットキーは `chrome://extensions/shortcuts` で変更できます。

### バージョンと更新履歴

ライブラリ左下の **「Recall v◯.◯.◯」** をクリックすると、バージョン情報と更新履歴が開きます。
拡張機能を新しくしたあと最初にライブラリを開いたときは、上部に「更新されました」のお知らせが出て、そこから変更点を確認できます。

## バグチェックとテスト（自動）

このフォルダにはテスト一式が入っています。コードをいじった後や、動作が怪しいときに走らせてください。

```bash
cd recall
npm test          # 静的チェック → ロジック → 実ブラウザ の順に全部実行
```

初回だけ、実ブラウザのテストに必要なものを入れます（静的チェックとロジックのテストは無しでも動きます）。

```bash
npm install
npm run setup:browser
```

個別に走らせることもできます。

- 保存に失敗したときに、ポップアップが固まる／ライブラリが以後更新されなくなる問題を直しました。
- ハッシュで画面を切り替えるサイトで、別ページが同じページとみなされ上書きされる問題を直しました。
- 大文字小文字が意味を持つ URL（短縮 URL など）を誤って重複と判定する問題を直しました。
- アドレスバーの rc 検索で、候補を選ばず Enter したときに検索語が捨てられる問題を直しました。
- 読み込みが途中で失敗しても成功と表示される問題、ID が衝突した項目が黙って消える問題を直しました。

- 一括操作のカテゴリ一覧が、カテゴリを追加・削除しても更新されない問題を直しました。
